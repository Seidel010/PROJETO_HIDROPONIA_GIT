# 🎨 HidroVerde - Estudo de HTML e CSS para Design de Dashboard

Este repositório é um **estudo prático em Front-end**, focado na aplicação de **HTML e CSS** para a criação de um dashboard conceitual. O objetivo foi desenvolver uma interface limpa e intuitiva para um sistema de gestão de hidroponia.

---

## 💡 Foco Técnico e Habilidades Demonstradas

Este projeto simples demonstra o domínio de técnicas essenciais de Front-end:

* **Desenvolvimento Front-end (HTML/CSS):** Criação de uma interface organizada, utilizando apenas HTML para a estrutura e CSS para todo o design, estilo e animação.
* **Design de Interface (UI/UX):** Foco na experiência do usuário (UX) com uma navegação clara (Sidebar) e um design moderno e amigável (Tema Verde/Gradient).
* **Controle de Layout:** Uso efetivo de `flexbox` para o posicionamento da Sidebar e do Conteúdo Principal, garantindo a organização visual da página.
* **Estilização Avançada:** Aplicação de gradientes (`linear-gradient`), sombreamento (`box-shadow`) e transições CSS para criar um design polido e interativo.

## 🎨 Estrutura do Código

* **HTML:** Estrutura a página, definindo a Sidebar (`.sidebar`) e a Área de Conteúdo (`.content`).
* **CSS (Inline na tag `<style>`):** Contém toda a lógica de layout e design, com destaque para a estilização do menu interativo (`.menu-item:hover`).

---

## ⚙️ Próximos Passos (Evolução do Projeto)

O projeto é uma excelente base para o próximo nível de aprendizado:

1.  **Interatividade:** Introduzir **JavaScript** para gerenciar a troca de conteúdo na página, simular dados e tornar o dashboard funcional.
2.  **Organização CSS:** Migrar o CSS para um arquivo externo (`styles.css`) e aplicar metodologias de organização (ex: BEM).
3.  **Aprimoramento de Design:** Refinar a responsividade para garantir visualização perfeita em diferentes tamanhos de tela.
